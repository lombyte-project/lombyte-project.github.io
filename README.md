# lombyte-project.github.io

Website of [Lombyte](https://github.com/lombyte-project/lombyte), served at
https://lombyte-project.github.io/. Edit `site/`; the `pages` workflow builds it
with data from the game repository and deploys on every push, hourly and on
demand.

`site/namingdesk.html` is the Naming Desk, served at `/namingdesk`. The files
in `site/naming-data/` are a snapshot of the game repository (source, names,
symbol files), refreshed with each Desk release.
