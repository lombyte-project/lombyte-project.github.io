About the project

  • 01 · Goal

    What is Lombyte?

    A matching decompilation of Ratchet & Clank for PS2: every function is rewritten in C until the reconstructed compiler produces identical machine code.

  • 02 · Legal

    Does it include the game?

    No. Lombyte contains no game data, executables or disc images. You need your own copy of the USA release (SCUS_971.99).

  • 03 · Scope

    Is this a PC port or a recomp?

    No. Lombyte is a decompilation, not a recomp: it rebuilds the original source code as C.

  • 04 · Join

    Can I help?

    Yes. Pick a function, match it and open a pull request; the contributing guide covers the setup.
