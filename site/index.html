About the project

  • 01 · Goal

    What is Lombyte?

    A matching decompilation of Ratchet & Clank for PS2: every function is rewritten in C until the original compiler produces identical machine code.

  • 02 · Legal

    Does it include the game?

    No. Lombyte contains no game data, executables or disc images. You need your own copy of the USA release (SCUS_971.99).

  • 03 · Future

    Is this a PC port?

    Not yet. A fully matching decompilation comes first; a native port is the long-term goal.

  • 04 · Join

    Can I help?

    Yes. Pick a function, match it and open a pull request. The contributing guide covers the setup.
